Email Domains Mapper

Connect users to the right mail servers based on their email domain.

Features Requirements Install Config generator Changelog

What it does

For Roundcube installations serving multiple email domains. You configure which domains are allowed and which IMAP, SMTP and optional ManageSieve servers each domain uses. Users sign in with their full email address; the plugin looks up the domain and selects the configured servers. Unknown or malformed domains are rejected before any connection is made.

Explicit domain allowlist (fail-closed)
IMAP + SMTP host selection per domain
Optional per-domain ManageSieve
ManageSieve UI/endpoint gating
IDN (Unicode/punycode) support
Case-insensitive domain matching
TLS-only server URLs (ssl://, tls://)
Configurable logging with sanitization

Requirements

  • Roundcube 1.7 or newer
  • PHP 8.1 or newer
  • intl and mbstring PHP extensions
  • Mail server URLs using tls:// or ssl://

Installation

From your Roundcube installation directory:

composer require pushpasta/email_domains_mapper

Composer installs under plugins/. If prompted to enable the plugin, answer yes. config.inc.php is preserved across updates.

Then complete the configuration below.

Configuration generator
